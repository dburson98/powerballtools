powerballtools
==============

Small R package to explore historical Powerball results (2010+).  


What it does
------------

- Loads past Powerball draws  
- Finds most common numbers  
- Makes random tickets (normal or weighted)  
- Checks how a ticket would have done in past draws  

This package is a small project I built to explore Powerball lottery data in R. It includes every Powerball drawing from 2010 to today and a few functions that let you work with the numbers in a simple way. You can look at the most common white balls or powerballs. Also lets you make random tickets, and check how a ticket would have matched old drawings. I also made a vignette that walks through the main steps like loading the data, viewing the structure, making plots, and testing a ticket.
I followed the package guidelines from class. I created a DESCRIPTION file, added documentation, wrote tests with testthat, used debugging tools, and put everything together in R Markdown. The goal was to build something that works, is easy to understand, and shows what I learned during the semester. It was interesting to incorporate a dataset like this in which i have a interest in.
