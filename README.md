My project was an R package called powerballtools that works with historic Powerball lottery drawings. The package includes a built-in dataset of past draws and functions to explore the numbers. You can look at which white balls and Powerballs show up most often, choose to generate example Powerball tickets, and check how a ticket would have matched against past drawings. The goal of the package is to give users an easy way to load the data, and play with ticket ideas inside R.
